# EQ 程序 GS 图像分析报告

## 概述

运行 `./eq <in/eq.ITER01.in` 命令生成了 **20 页** GS 图像，这些图像通过 **EQGR1D** 函数绘制。

## EQGR1D 函数说明

**函数签名：**
```fortran
SUBROUTINE EQGR1D(GX1,GX2,GY1,GY2,GX,GY,NXM,NXMAX,NGMAX,STR,MODE)
```

**参数说明：**
- `GX1, GX2, GY1, GY2`: 图形在页面上的位置坐标（cm）
- `GX`: X 轴数据数组
- `GY`: Y 轴数据数组（可以包含多条曲线）
- `NXM`: 数组维度
- `NXMAX`: 实际数据点数
- `NGMAX`: 曲线数量
- `STR`: 图形标题字符串（格式：@TITLE@）
- `MODE`: 绘图模式
  - 0: Y轴从0开始（如果数据包含0）
  - 1: Y轴自动缩放
  - 其他值控制交互式输入等

## 生成的图像详细信息

### 命令流程分析

根据输入文件 `in/eq.ITER01.in`：
1. 命令 `s` → 调用 `EQGS2D` 和 `EQGS1D(0)`
2. 命令 `s` → 再次调用，生成更多图形

### EQGS1D 函数生成的图形

`EQGS1D(MODE)` 根据 MODE 参数决定 X 轴坐标：
- `MODE=0`: X 轴为归一化极向磁通 PSIP
- `MODE=1`: X 轴为归一化环向半径 RHOT
- `MODE=2`: X 轴为归一化环向磁通 PSIT

## EQGS2D 函数生成的图形

`EQGS2D` 生成 2D 等高线图，包括：
- 等离子体边界和磁面轮廓
- 磁通量面分布
- 压强和电流密度分布

---

## 其他绘图函数调用

### EQGC1D (计算结果的 1D 图形)
在 MODE=1 时调用，绘制：
- 极向磁通 ψp
- 电流密度 Jt
- 压强 P
- 温度 T

### EQGC2D (计算结果的 2D 图形)
绘制 R-Z 平面的等值线图

## 代码确认

**是的，所有 1D 图形都使用 `EQGR1D` 函数绘制。**

从代码分析可以看出：
1. `eqgout.f` 中的 `EQGS1D` 函数调用了 **23 次** `EQGR1D`
2. 每次调用绘制一个或多个曲线
3. 使用 `CALL PAGES` 和 `CALL PAGEE` 管理页面
4. 共生成 **6 个页面**的 1D 图形（通过 EQGS1D）

## 数据提取建议

如果需要保存这些图形数据到表格，可以：

1. **修改 `EQGR1D` 函数**，在绘图前将数据写入文件
2. **在 `EQGS1D` 中添加输出**，直接保存 GX, GY 数组
3. **读取 eqdata.ITER01 文件**，这是包含所有计算结果的二进制文件

建议使用方法 2 或 3，避免修改底层绘图函数。
