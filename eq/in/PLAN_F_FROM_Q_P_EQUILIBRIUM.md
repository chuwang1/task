# “从安全因子 \(q\) 和压强 \(p\) 求解自洽托卡马克平衡”实施计划

## 1. 目标概述
利用现有的 Grad-Shafranov (GS) 方程求解器 (`solve_gs_from_gfile.py`) 与 EQIPQP 极向场反推器 (`compare_f_from_gfile_geom_q.py` 及相关库)，构建一个**全自洽的平衡求解代码 (Fixed-boundary Equilibrium Solver)**。
给定等离子体矩形边界的磁通约束、参考纵场 \(B_0\)、大半径 \(R_0\)、以及目标剖面 \(p(\rho_{tor})\) 和 \(q(\rho_{tor})\)，通过外层非线性迭代，最终收敛出满足物理平衡的 \(\psi(R,Z)\) 与极向电流函数 \(F(\psi)\)。

---

## 2. 核心架构与迭代环 (Outer Iteration Loop)

我们将采用“几何-电流解耦迭代”的框架。整个计算划分为一个大的外层循环，每次循环包含四个主要模块：

### 模块 A：磁面追踪与几何提取 (Geometry Tracker)
- **输入**：当前的二维磁通分布 \(\psi^{(k)}(R,Z)\)。
- **操作**：
  1. 寻找磁轴 \((R_{axis}^{(k)}, Z_{axis}^{(k)})\) 并确定轴磁通 \(\psi_{mag}^{(k)}\)。
  2. 提取 \(\psi_{bdy}^{(k)}\)（LCFS 上的磁通值）。
  3. 在 \([\psi_{mag}^{(k)}, \psi_{bdy}^{(k)}]\) 区间内划分 \(N\) 个等通量面，利用 `contourpy` 提取闭合曲线。
  4. 沿曲线积分，计算几何特征量：\(RSV^{(k)}, VPV^{(k)}, AVIR2^{(k)}, AVRR2^{(k)}\)。
- **输出**：当前磁场位形的纯几何量剖面（基于归一化磁通 \(\psi_n\)）。

### 模块 B：剖面映射与导数计算 (Profile Mapper)
- **输入**：用户提供的 \(p(\rho_{tor})\) 和 \(q(\rho_{tor})\)；模块 A 计算的 \(\psi_n\) 和环向磁通 \(\Phi\)。
- **操作**：
  1. 利用 \(\Phi\) 计算当前的 \(\rho_{tor}^{(k)}\) 坐标系。
  2. 将目标 \(p\) 和 \(q\) 从 \(\rho_{tor}\) 空间映射（插值）到当前的 \(\psi_n\) 网格上。
  3. 计算压强对真实极向磁通的导数：\(dp/d\psi_p^{(k)}\)。
- **输出**：当前 \(\psi_n\) 网格上的 \(q\) 与 \(dp/d\psi_p\) 剖面。

### 模块 C：电流函数重建 (EQIPQP Reconstructor)
- **输入**：模块 A 的几何量；模块 B 的 \(q\) 与 \(dp/d\psi_p\)。
- **操作**：
  1. 从边界 \(F_N = 2\pi R_0 B_0\) 开始向内梯形积分。
  2. 求解出极向电流函数 \(F^{(k)}(\psi_n)\)。
  3. 计算其导数项：\(FF'^{(k)} = F \cdot dF/d\psi_p\)。
- **输出**：GS 方程右端项所需的 \(FF'^{(k)}(\psi_n)\) 剖面。

### 模块 D：GS 方程内层求解 (Inner GS Solver)
- **输入**：模块 B 的 \(p'^{(k)}\)；模块 C 的 \(FF'^{(k)}\)；上一轮的 \(\psi^{(k)}(R,Z)\)。
- **操作**：
  1. 将一维的 \(p'\) 和 \(FF'\) 映射回二维网格 \((R,Z)\) 上，形成右端源项 \(J_\phi(R,Z)\)。
  2. 维持矩形边界的 Dirichlet 约束不变。
  3. 利用有限差分离散的 \(\Delta^*\) 算子（五点差分），求解线性方程组（稀疏矩阵求逆）。
  4. 得到未经松弛的试探解 \(\psi_{new}(R,Z)\)。
- **输出**：新的磁通分布 \(\psi_{new}(R,Z)\)。

### 欠松弛与收敛判定 (Relaxation & Convergence)
- **操作**：
  1. 使用重度欠松弛防止数值震荡：\(\psi^{(k+1)} = \alpha \psi_{new} + (1-\alpha)\psi^{(k)}\)（如 \(\alpha=0.1\sim 0.3\)）。
  2. 计算残差：\(\epsilon = ||\psi^{(k+1)} - \psi^{(k)}||_\infty\)。
  3. 若 \(\epsilon < \text{Tol}\)，则收敛；否则进入 \(k+1\) 步。

## 3. 实施步骤与分期里程碑

### Phase 1: 模块重构与接口打通 (Infrastructure)
1. **剥离 GS 求解核心**：将 `solve_gs_from_gfile.py` 中构建稀疏矩阵和求解器（`spsolve`）的代码封装为独立函数 `solve_gs_step(psi_old, pprime_1d, ffprime_1d, ...)`。
2. **剥离几何提取核心**：将 `reconstruct_eqcalv_from_gfile.py` 中的等值面提取与数值积分封装为 `extract_geometry(psi_2d, R, Z, ...)`。要求能自动追踪并更新磁轴 \((R_{axis}, Z_{axis})\) 和极值 \(\psi_{mag}\)。
3. **接口连通测试**：构建主控脚本 `solve_eq_from_q_p.py`，将四个模块串联起来，**但不进入真实循环**（只跑单步 \(k=1\)），验证数据流通是否顺畅，单位（如 \(2\pi\) 因子）是否一致。

### Phase 2: “温和”扰动的自洽收敛测试 (Smoke Test)
1. **输入准备**：读取一个稳定的参考 G-file（如 `g260206.20000_teq_0114`）。直接从该 G-file 中提取初始 \(p(\rho)\) 和 \(q(\rho)\) 作为**目标输入**。
2. **启动外层迭代**：设置容差 \(\text{Tol} = 10^{-5}\)，松弛因子 \(\alpha = 0.2\)。
3. **观察行为**：
   - 如果算法正确，经过 20-50 步外层迭代后，\(\psi(R,Z)\) 应该稳定在初始 G-file 附近不发生漂移。
   - 记录每一步的沙弗拉诺夫位移（磁轴 \(R_{axis}\) 的变化）和残差下降曲线。

### Phase 3: 大幅度修改剖面演化与稳定性调优 (Stress Test)
1. **升压强实验 (High Beta_p)**：保持目标 \(q(\rho)\) 不变，人为将目标 \(p(\rho)\) 放大 1.5 倍或 2 倍。
2. **运行迭代**：观察等离子体磁轴是否成功向外侧（大半径侧）物理性漂移，且等值面形状是否发生合理的挤压（D 形变）。
3. **稳定性调优 (Stabilization Arsenal)**：
   - 极大概率在这一步会遇到高频震荡（尤其在磁轴和边界附近）。
   - **对策 A**：在 `extract_geometry` 之后，对提取出的一维几何量（\(RSV, VPV, AVIR2, AVRR2\)）施加平滑滤波器（如 Savitzky-Golay 或样条拟合），滤除轮廓提取带来的离散噪音。
   - **对策 B**：对 EQIPQP 重建出的 \(F\) 和计算出的 \(FF'\) 再次进行平滑。
   - **对策 C**：动态调整松弛因子 \(\alpha\)。

### Phase 4: 输出规范化与诊断 (Output & Diagnostics)
1. **最终状态导出**：当达到收敛后，将最终的 \(\psi(R,Z), F(\psi), p(\psi), q(\psi)\) 以及磁轴、边界坐标等写入一个新的标准 GEQDSK 格式文件（G-file），或者输出详细的 CSV 报告。
2. **可视化诊断面板**：生成一张多面板摘要图（Summary Plot），包含：
   - \(\psi(R,Z)\) 的等值面演化对比（初始态 vs 最终态）。
   - 收敛历史（残差随迭代步数的变化对数图）。
   - 输入的 \(q\) 和 \(p\) 与最终映射回 \(\psi_n\) 上的匹配度。
   - 重建出的 \(F\) 与原始状态的对比。

---

## 4. 潜在风险与备用方案

1. **等值面提取在迭代早期破裂（Topology Change）**
   - **风险**：如果第一步求解出的 \(\psi_{new}\) 极度扭曲，可能出现多个磁轴（磁岛）或等值面无法闭合，导致 `contourpy` 失败。
   - **备用方案**：在迭代最初几步使用极小的松弛因子（如 \(\alpha=0.05\)）；当轮廓提取失败时，沿用上一轮的几何量退化计算。

2. **磁轴处的 \(0/0\) 奇异性导致 \(FF'\) 爆炸**
   - **风险**：EQIPQP 在磁轴处的借点近似在严重变形的磁面下可能失效。
   - **备用方案**：在轴附近（如 \(\psi_n < 0.05\)）强制使用多项式拟合或二阶平滑外推，拒绝使用原始的粗糙积分值。
