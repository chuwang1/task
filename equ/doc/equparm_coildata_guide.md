# TASK/EQU 输入参数说明文档

> 文档更新日期：2026/01/15

本文档说明 TASK/EQU 平衡计算程序的两个主要输入文件：`equparm` 和 `coildata`。

---

## 一、equparm 文件参数说明

`equparm` 是 TASK/EQU 的主要输入参数文件，使用 Fortran NAMELIST 格式（`&EQU ... &END`）。

### 1.1 计算区域参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `RWMN` | R | 1.90 | 计算区域的最小 R 坐标 [m] |
| `RWMX` | R | 4.20 | 计算区域的最大 R 坐标 [m] |
| `ZWMX` | R | 1.20 | 计算区域的最大 \|Z\| 坐标 [m] |
| `IUDSYM` | I | 0 | 上下对称性 (1=对称, 0=非对称) |
| `DEVICE` | C8 | 'JT60U' | 装置名称 |
| `KNAMCOIL` | C80 | 'init' | 线圈数据文件名 |

### 1.2 等离子体参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `RMAJ` | R | 3.05 | 大半径 [m] |
| `RPLA` | R | 0.9 | 小半径 [m] |
| `ZPLA` | R | 0.0 | 磁轴 Z 位置 [m] |
| `ELIP` | R | 1.0 | 椭圆度 (elongation) |
| `TRIG` | R | 0.0 | 三角形变形度 (triangularity) |
| `BTV` | R | 13.5 | 环向磁场 × 大半径 R*Bt [mT] |
| `TCUR` | R | 2.0 | 等离子体电流 Ip [MA] |
| `QAXI` | R | 1.0 | 轴心安全因子 q |
| `XXLI` | R | 1.0 | 内感 |

### 1.3 电流剖面参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `ICP(i)` | I | dp/ds 和 dF/ds 剖面选项标识 |
| `CP(i)` | R | dp/ds 和 dF/ds 剖面系数 (i=1..10) |

**ICP(1) 选项说明：**
- `ICP(1)=1`: pds0=(1-cp4)*(1-v^cp2)^cp3+cp4
- `ICP(1)=2`: pds0=1-cp2*v^cp3-(1-vp2+cp4)*v^cp5
- `ICP(1)=9`: 见 eqpfds.f 中的 subroutine eqpfds
- `ICP(1)=11`: 中空电流剖面

### 1.4 极向场线圈控制参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `IVAC(k)` | I(0:13) | 线圈模型标识 |
| `NCOIL(k)` | I(0:13) | 线圈匝数 |
| `CVAC(k)` | R(0:13) | 线圈电流 [AT] |
| `CVACST(k)` | R(13) | 线圈电流初始值 [AT] |
| `CVACWG(k)` | R(13) | 线圈电流权重 |
| `CVACT(k)` | R(13) | 线圈电流时间导数 [AT/s] |

**IVAC 取值说明：**
- `IVAC(k) < 0`：该线圈电流**固定**不变
- `IVAC(k) >= 0`：该线圈电流**可调节**（用于平衡计算优化）

### 1.5 分界面/X点参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `ISEP` | I | 2 | X点类型 |
| `DSEP` | R | 0.001 | X点与最后封闭磁面的距离 |

**ISEP 取值说明：**
- 0: 无 X 点
- 1: 下 X 点
- 2: 外 X 点 (JFT-2a)
- 3: 上 X 点
- 4: 内 X 点

### 1.6 收敛控制参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `MSETUP` | I | 20 | 初始平衡最大迭代次数 |
| `ESETUP` | R | 1.D-3 | 初始平衡收敛判据 |
| `IEQMAX` | I | 20 | FCT 平衡最大迭代次数 |
| `EEQMAX` | R | 1.D-3 | FCT 平衡收敛判据 |
| `IADMAX` | I | 1 | 真空场调整最大迭代次数 |
| `EADMAX` | R | 1.D-4 | 真空场调整收敛判据 |

### 1.7 标记点参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `MSFX` | I | 标记点数量 |
| `RVAC(i)` | R | 标记点 R 坐标 |
| `ZVAC(i)` | R | 标记点 Z 坐标 |

- `MSFX > 0`：从 RMAJ, RPLA, ELIP, TRIG 生成 RVAC, ZVAC
- `MSFX < 0`：从 RVAC, ZVAC 反推 RMAJ 等参数

## 二、coildata 文件格式说明

`coildata` 定义极向场线圈的几何位置数据。

### 2.1 文件格式

```
#线圈编号-线圈名称
   R坐标    Z坐标    电流系数
   R坐标    Z坐标    电流系数
   ...
#下一线圈
   ...
```

### 2.2 每行数据含义

| 列 | 含义 | 单位 |
|----|------|------|
| 第1列 | R 坐标（大半径方向位置） | m |
| 第2列 | Z 坐标（垂直方向位置） | m |
| 第3列 | 电流系数（该匝的相对电流权重） | - |

## 三、IVAC/NCOIL 与 coildata 的对应关系

### 3.1 读取逻辑

代码按 `NCOIL(1), NCOIL(2), NCOIL(3)...` 的顺序从 coildata 文件中**顺序读取**：

```fortran
do n=1,icvdm
   if(ncoil(n).gt.0)then
      read(nid,'(a10)')aname           ! 读取线圈名称行
      do nn=1,ncoil(n)                 ! 读取 ncoil(n) 匝数据
         read(nid,'(3d10.3)') rcoil(nn,n),zcoil(nn,n),ccoil(nn,n)
      enddo
   endif
enddo
```

### 3.2 对应规则

1. **按顺序读取**：只有 `NCOIL(n) > 0` 的线圈组才会读取数据
2. **匝数匹配**：`NCOIL(n)` 的值必须与 coildata 中对应线圈组的数据行数一致
3. **名称行跳过**：coildata 中的 `#...` 注释行仅供阅读，代码会读取但不解析

### 3.3 示例对应

假设 equparm 中设置：
```
NCOIL( 1)=10, NCOIL( 2)=10, NCOIL( 3)=4, NCOIL( 4)=4, NCOIL( 5)=4, NCOIL( 6)=4
```

则 coildata 应按顺序包含：
```
#1-PF4-1        ← NCOIL(1)=10，读取下面10行
   0.1545   -0.5816     0.10
   ... (共10行)

#2-PF4-2        ← NCOIL(2)=10，读取下面10行
   0.1630   -0.0247    0.05
   ... (共10行)

#8 PF1          ← NCOIL(3)=4，读取下面4行
   1.5415   -0.5814     0.25
   ... (共4行)

#9 PF2          ← NCOIL(4)=4，读取下面4行
   ...

#10 PF3-1       ← NCOIL(5)=4，读取下面4行
   ...

#11 PF3-2       ← NCOIL(6)=4，读取下面4行
   ...
```

### 3.4 注意事项

> [!IMPORTANT]
> - coildata 中的线圈名称（如 `#1-PF4-1`）与 NCOIL 数组索引**无直接关联**
> - 对应关系**完全由读取顺序决定**
> - 如果 `NCOIL(n)=0`，则跳过该索引，不从文件读取任何数据
