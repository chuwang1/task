# 外部输运系数读取与基于定标公式的输运模型配置说明

本次更新在 TRX 模块中引入了**外部输运系数（$\chi$ 场）读取**功能，以及**基于约束时间定标公式（如 IPB98(y,2)）自适应调节异常输运强度的模型**。这些功能已从先前的 `latest` 版本成功迁移至当前的 `CFEDR` 分支。

## 1. 外部输运系数文件读取 (`trfixed.f90`)

通过在 namelist `&TR` 中配置文件名和读取模式，可以将预先设定好的空间分布（如 COREDIV 程序的输出）作为背景输运系数读入程序。

### 相关输入参数 (Namelist `&TR`)
*   `knam_chifixed` (字符串): 外部输运系数数据文件的文件名，默认为 `'Chi_Se_COREDIV.DAT'`。文件格式应为以空格分隔的多列数据，其中第1列为 $r$，第4列为 $\chi_e$，第5列为 $\chi_i$。
*   `model_chifixed` (整数，默认值 0):
    *   `0`：关闭外部读取，完全使用程序内部计算的模型 $\chi$。
    *   `1`：读取文件，同时对核心区域（$r/a < 0.4$）的 $\chi$ 降低一半（$\times 0.5$）。
    *   `2`：读取文件，同时对核心区域（$r/a < 0.4$）的 $\chi$ 乘以 `chifixed_factor`。
    *   `3`：读取文件，同时对边界区域（$r/a > 0.5$）的 $\chi$ 乘以 `chifixed_factor`。
*   `chifixed_factor` (实数，默认值 1.0): 配合 `model_chifixed=2,3` 时的乘积因子。

## 2. 基于约束定标律的输运模型 (`MDLKAI=170~189`)

### 2.1 纯外部形状缩放模型 (`MDLKAI=170~179`)
*   当 `MDLKAI=170:179` 时，不使用内部异常输运模型。
*   异常输运系数 $\chi$ 完全等于外部读入的剖面数据，并分别乘以常系数：$\chi_e = CK0 \times \chi_{ext\_e}$，$\chi_i = CK1 \times \chi_{ext\_i}$。

### 2.2 定标归一化自适应输运模型 (`MDLKAI=180~189`)
这是用于模拟整体约束满足指定定标公式分布的模型，$\chi$ 分布形状由外部文件决定，但总体强度由程序通过 $C_{scaling}$ 因子在时间演化中自动调节，从而使模拟出的总体约束时间 $\tau_E$ 向目标约束时间 $\tau_{target}$ 收敛。

*   `MDLKAI=180`: 目标约束时间为 ITER89-P L模标度 ($\tau_{E,89}$)。
*   `MDLKAI=181`: 目标约束时间为 IPB98(y,2) H模标度 ($\tau_{E,98}$)。
*   `MDLKAI=182`: 目标约束时间为 `H_FACTOR_USER` $\times \tau_{E,89}$。
*   `MDLKAI=183`: 目标约束时间为 `H_FACTOR_USER` $\times \tau_{E,98}$。

### 自定义缩放参数 (Namelist `&TR`)
*   `C_SCALING` (实数, 默认 1.0): 初始异常输运放大乘子。$\chi_e = C_{scaling} \times \chi_{ext\_e} \times CK0$。此参数会在演化中被程序自动更新（可以通过 log 查看其变化过程）。
*   `ALPHA_RELAX` (实数, 默认 0.5): 步进调节收敛率（弛豫因子）。建议范围 0.3 ~ 0.7。其值越小计算越稳定，越大越容易震荡但收敛更快。
*   `H_FACTOR_USER` (实数, 默认 1.0): 作为 `MDLKAI=182,183` 模式下的 $H$ 因子乘数（例如设置为 1.2 以模拟 $H_{98}=1.2$ 的改善约束）。
*   `C_SCALING_MIN`, `C_SCALING_MAX`: $C_{scaling}$ 的自调节限幅范围，默认为 0.1 ~ 10.0。

## 3. 实现与文件修改概览

本次功能的迁移与实现涉及以下源程序的修改：
1.  **数据结构** (`trcomm.f90`, `trinit.f90`, `trparm.f90`, `trview.f90`): 加入上述输入变量的声明、默认初始化、Namlist 配置与控制台屏幕显示。加入 `AKEXT_E` 与 `AKEXT_I` 全局数组以存储读入插值后的外部剖面。
2.  **文件读取模块** (`trfixed.f90`, **新增**): 实现子程序 `tr_prep_chifixed`，执行文件加载与网格线性插值，并在主初始化阶段 (`trprep.f90`) 调用。
3.  **模型核心** (`trcoef.f90`): 在子程序 `TRCFDW` 中实现 `CASE(170:189)` 的逻辑；在 `TRCFNC` 后继处理流程中加入 `model_chifixed=1~3` 覆盖修改内部原输运系数的逻辑。
4.  **时间演化中自调节算法** (`trloop.f90`): 插入子过程 `tr_scaling_adjust(NT)`，于每个时间步 `NT` 评估温度演化得到的积分 $\tau_E$ 相对于 $\tau_{target}$ 的误差，并按照限幅弛豫算法稳定更新 `C_SCALING`，直至满足 1% 容差即标记收敛 `L_SCALING_CONVERGED=.TRUE.`。
5.  **编译依赖** (`Makefile`): 添加新对象文件 `trfixed.o` 进入程序主链接链。
